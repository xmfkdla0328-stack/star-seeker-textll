---
name: 개발 프리뷰 저장 초기화
description: 브라우저 저장 데이터가 새로고침 뒤에도 남는 개발 프리뷰의 온보딩 반복 테스트 정책
---

개발 프리뷰에서는 첫 접속 온보딩을 반복 검증할 수 있도록 새로고침 시 게임 저장 데이터를 초기화한다. 이 동작은 Vite의 개발 환경 플래그로 감싸며, 운영 빌드에서는 실행하지 않는다.

**Why:** `localStorage`는 개발 서버를 재시작하거나 페이지를 새로고침해도 유지되므로, 이전 테스트에서 완료된 튜토리얼 상태가 다음 테스트를 가릴 수 있다.

**How to apply:** 이어하기·프로필 보존을 테스트할 때는 개발 초기화 코드를 임시로 끄거나 운영 빌드/별도 브라우저 프로필에서 검증한다.
